01 · Why slim wins

Built for the floor space
you actually have.

Every dart machine sells the same game. EDmini sells the footprint, the weight and the install — the three numbers a venue owner feels on day one.

The playing head is 11 cm from segment to back wall. The full MAX configuration is 58 cm wide and 35.3 cm deep at the base — a tower, not a cabinet.

65 kg for the whole machine. The conventional “P” cabinet on DARTMAN’s own comparison table weighs 160 kg; the “D” cabinet 124 kg. Delivery stops being an event.

Install
0person

Modules, not a monolith.

Three assembly styles, no tools, single-person install. Any module swaps out for repair — the screen, the head, the coin unit — so a fault never takes the whole machine off the floor.

Shipping
0units

Ships flat. Stacks tall.

Three cartons per machine — main box, cabinet, screen — 180 units in a 40′ container, 85 in a 20′. Stackable in the stockroom before they hit the floor.
